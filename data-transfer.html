Export a time range

Select main articles by publication date, inclusive, in Europe/Oslo time, including unlocated inbox stories. Each selected incident includes all its follow-ups, comments, cached text, and uploaded PDFs, even if a follow-up falls outside the date range.

Import an archive

Upload the exported ZIP on the destination installation. Records are added with new local IDs. Reimporting from the same source adds new records and keeps previously imported records and local edits. Existing destination data is preserved.

Authors are preserved as separate contributor accounts with no source passwords, email addresses, or admin roles. Sign in using the destination’s own admin account.

Cached text and uploaded PDFs are included for offline reading. Remote thumbnails, map tiles, and CDN-hosted map libraries are not included in the archive. A fully offline map needs local libraries and tile services.
